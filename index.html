Open API 주요 서비스

    투자 데이터를 내 방식대로

    시세,종목,계좌,잔고 정보를 원하는 환경에서 자유롭게 활용하세요.

  • SERVICE 02

    투자 기능을 손쉽게 연동

    투자정보 조회부터 주문.체결까지 필요한 기능을 서비스와 연결할 수 있습니다.

  • SERVICE 03

    투자 서비스 자동화

    자동매매, 투자 대시보드, AI 투자비서 등 다양한 투자 서비스를 구현 할 수 있습니다.

  • SERVICE 04

    보안 인증 기반 API환경

    Token 기반 인증 체계로 안정적인 API 이용 환경을 제공합니다.
